# TuryShop – E-commerce Web Application

TuryShop is a bachelor thesis web application for an online clothing store, built with PHP, SQL and XAMPP.

The project was developed as a complete academic web application, focused on product presentation, shopping cart functionality, user interaction and order-related flows.

## Main Features

- Product listing and product detail pages
- Shopping cart functionality
- Add to cart, update cart and remove from cart actions
- Checkout flow
- Order success page
- User authentication structure
- Admin area for managing store-related content
- Contact, gallery, about and size guide pages
- Database connection and configuration files
- Responsive styling through CSS
